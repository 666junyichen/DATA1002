# 项目说明

## 中文

项目名称：Global Health Indicator Prediction

时间：2022

项目类型：Academic data analytics project

我的角色：Predictive modelling contributor / data analyst

使用工具：Python, pandas, NumPy, scikit-learn, matplotlib, Jupyter Notebook

我负责的内容：

- 使用清洗后的全球健康指标数据进行预测建模。
- 选择与儿童和婴儿健康结果相关的解释变量。
- 构建并比较多种回归模型。
- 使用 RMSE 和 R-squared 对预测结果进行评估。
- 通过图表对预测值和真实值进行可视化对比。

数据来源：

- Cleaned SDG Goal 3 health indicator dataset
- Indicators include mortality, birth attendance, health coverage, adolescent birth rate, and health worker density fields

分析方法：

- Train/test split
- Feature selection for health outcome prediction
- Linear regression
- K-nearest neighbors regression
- Support vector regression
- Bayesian ridge regression
- RMSE and R-squared evaluation

最终结果：

- 准备了包含 163 条记录、28 个字段的全球健康指标清洗数据集。
- 数据覆盖 Europe, Asia, Oceania, Americas, Africa 五个区域。
- 数据年份覆盖 2000, 2005, 2010, 2015。
- 对多个回归模型进行训练、预测和评估，并记录模型表现差异。

可以写进简历的量化成果：

- Prepared and modelled a 163-record, 28-field global health dataset covering five regions and four time periods.
- Compared regression approaches for health outcome prediction using RMSE and R-squared as evaluation metrics.
- Achieved high-performing model results in selected experiments, including K-nearest neighbors regression with R-squared above 0.94 in recorded evaluations.
