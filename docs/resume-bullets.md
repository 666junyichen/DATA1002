# Resume Bullets

This file is for extracting resume-ready wording from the project. It is not part of the public project introduction.

## English Options

- Cleaned and integrated four public economic datasets with Python and pandas, producing a 36-row, 35-feature monthly analytical dataset covering 2019-2021.
- Built grouped summaries and matplotlib visualizations to communicate COVID-19 economic impact trends across travel, employment, public transport, and international education indicators.
- Quantified airport passenger movement decline from 44.4M in 2019 to 7.9M in 2021 using cleaned annual aggregation logic.
- Analysed labour market indicators and identified a 2020 average underemployment peak of 10.56%, compared with 8.33% in 2019 and 8.18% in 2021.
- Prepared and modelled a 163-record, 28-field global health indicator dataset covering five regions and four time periods.
- Compared linear regression, K-nearest neighbors regression, support vector regression, and Bayesian ridge regression using RMSE and R-squared evaluation metrics.

## 中文选项

- 使用 Python 和 pandas 清洗并整合四类公开经济数据，构建覆盖 2019-2021 年的 36 行、35 字段月度分析数据集。
- 构建分组汇总和 matplotlib 可视化，展示旅行、就业、公共交通和国际教育指标中的疫情期间经济变化趋势。
- 通过年度聚合量化机场客流变化，识别客流从 2019 年 44.4M 降至 2021 年 7.9M。
- 分析劳动力市场指标，发现 2020 年平均 underemployment rate 达到 10.56%，高于 2019 年 8.33% 和 2021 年 8.18%。
- 整理并建模一个包含 163 条记录、28 个字段、覆盖五个区域和四个年份的全球健康指标数据集。
- 对比线性回归、K 近邻回归、支持向量回归和贝叶斯岭回归，并使用 RMSE 与 R-squared 评估模型表现。

Applied data analytics project using Python to clean multi-source public datasets, build visual economic trend analysis, and compare regression models for global health outcome prediction.

使用 Python 完成多源公开数据清洗、经济趋势可视化分析和全球健康结果预测建模对比的应用数据分析项目。
